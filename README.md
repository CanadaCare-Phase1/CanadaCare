# CanadaCare
CanadaCare
Healthcare Access & Coordination Platform

Version: 0.1
Status: Research / Discovery
Project Lead: Rashmi 

Mission:
Make accessing healthcare more connected, transparent,
secure and patient-centred through technology.

Initial Target:
Diagnostic Imaging Referral Coordination
(MRI / CT)

Primary Users:
- Patients
- Referring Providers
- Healthcare Organizations
- Care Coordinators

Long-Term Vision:
A secure interoperability and healthcare coordination
platform connecting patients, providers and healthcare
organizations across fragmented healthcare systems.
